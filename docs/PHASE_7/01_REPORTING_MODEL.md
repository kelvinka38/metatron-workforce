# METATRON WORKFORCE — PHASE 7 / 01 REPORTING MODEL

**Authority:** `METATRON WORKFORCE — MASTER EXECUTION PLAN.md`
**Phase:** 7 — Reporting / Performance / Economic Evidence

## 1. Purpose

Define the operational reporting layer that lets Workers produce attributable reports and lets management inspect current institutional state without turning Workforce into an accounting, governance, or observation authority.

## 2. Report types

The model supports:

- daily reports;
- periodic reports;
- task reports;
- exception reports;
- incident reports;
- performance reports;
- economic reports.

Every material report preserves Worker identity, organizational context, reporting period, report type, evidence reference, and reporting time.

## 3. Management visibility

Management read models must make visible, where evidence exists:

- current work;
- completed work;
- blocked work;
- remaining capacity;
- staffing;
- performance;
- risks;
- exceptions;
- reported cost;
- budget context;
- economic evidence.

A dashboard is a read model. It does not grant approval, authorization, or execution authority.

## 4. Human management actions

The management layer must expose the information required for Humans to:

- review;
- approve;
- reject;
- request clarification;
- assign;
- reassign;
- escalate;
- monitor;
- compare.

The actual authority for those actions remains in the Phase 4/6 authority and authorization models.

## 5. Evidence boundary

A report is an operational statement backed by evidence. It is not automatically institutional truth merely because a Worker reported it.

Where a report contains inferred or estimated values, the implementation must preserve the distinction between evidence and inference.

## 6. Historical boundary

New reports and dashboard recalculation must not rewrite historical reports or execution evidence. Current dashboards may change as new evidence arrives, while historical records remain reconstructable.

## 7. Gate G7 relevance

This model supplies the reporting surface required to answer:

- What is happening?
- Who is doing it?
- Who is responsible?
- What is blocked?
- How much capacity remains?
- How much did it cost?
- Did we meet target?
- Why did we miss?
- What should happen next?
