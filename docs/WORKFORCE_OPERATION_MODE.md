\# WORKFORCE OPERATION MODE



Status: ACTIVE

Activation Date: 2026-08-23

Current Phase: Post-G12 Operational Execution



\---



\## 1. Purpose



This document defines the operating boundary after workforce production readiness certification.



The workforce system is no longer treated as an engineering experiment.



All future activities must use the workforce execution model.



\---



\# 2. Operating Principle



Human does not directly execute uncontrolled work.



Human defines:



\- Intent

\- Objective

\- Constraint

\- Acceptance criteria



Workforce executes:



\- Analysis

\- Planning

\- Validation

\- Evidence generation

\- Execution tracking



\---



\# 3. Mandatory Execution Flow



Every workforce task follows:



REQUEST

↓

CONTEXT LOAD

↓

PLAN GENERATION

↓

EXECUTION

↓

EVIDENCE COLLECTION

↓

VALIDATION

↓

DECISION



No execution without evidence.



\---



\# 4. Required Inputs Before Any Work



Worker must load:



\- Foundation documents

\- Current SOT

\- Relevant phase documentation

\- Existing execution state

\- Previous evidence



Unknown context = blocked execution.



\---



\# 5. Worker Responsibilities



Worker must:



\- never overwrite SOT without authorization

\- never create duplicate authority documents

\- maintain traceability

\- record assumptions

\- provide evidence



\---



\# 6. Human Responsibilities



Human owns:



\- strategic intent

\- final decisions

\- priority

\- business constraints

\- acceptance approval



Human does not manually manage every execution step.



\---



\# 7. Completion Definition



A task is complete only when:



1\. Implementation exists

2\. Validation passed

3\. Evidence generated

4\. State updated

5\. Decision recorded
