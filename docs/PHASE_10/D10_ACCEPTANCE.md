# PHASE 10 — ACCEPTANCE GATE

## G10 acceptance criteria

The primary vertical slice must demonstrate the complete institutional flow:

- Human request
- Head of Workforce responsibility assignment
- Farm Head planning
- staffing and capacity calculation
- resource and cost planning
- explicit authorization
- authorized execution
- failure preservation
- worker/farm reporting
- planned vs actual variance
- operational economic evidence compatible with P&L processing
- human review
- learning from execution evidence
- validated improvement
- next-cycle behavior reflecting the validated improvement
- mandatory provenance across material stages

## Ownership boundaries

The Phase 10 implementation does not become the owner of:

- Governance authority
- Authorization authority
- Gateway enforcement
- Execution infrastructure
- Observation truth
- Knowledge admission
- Economy accounting truth

## Gate

G10 = PASS only after the implementation and full repository test suite are accepted together.

Phase 11 is not started by this document alone.
