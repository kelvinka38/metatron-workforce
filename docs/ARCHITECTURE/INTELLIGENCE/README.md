## Semantic architecture lock

```text
HUMAN NATURAL LANGUAGE
        ↓
FRONTIER SEMANTIC COGNITION
        ↓
NORMALIZED REQUEST / OBJECTIVE
        ↓
INTELLIGENCE CASE / PLANNING AS APPLICABLE

Provider unavailability is an explicit failure state; it MUST NOT silently authorize a keyword bypass around the approved semantic boundary.
