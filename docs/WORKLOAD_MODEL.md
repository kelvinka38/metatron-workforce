# WORKLOAD_MODEL.md

## Status

APPROVED FOR CURRENT CERTIFICATION ENVELOPE

## Evidence Envelope

The current acceptance suite exercises:

- up to 1,000 representable workers;
- 64 concurrent workflow executions;
- multi-organization scenarios;
- multiple departments and teams;
- multiple worker classes;
- 8,000 available labor hours in the capacity scenario;
- failure and recovery scenarios;
- economic plan/actual/variance scenarios.

## Interpretation

These numbers define the verified certification envelope, not a forecast of production demand.

The workload model intentionally separates:

`representation capacity` ≠ `sustained production throughput`.

No unsupported production throughput claim is made from the 1,000-worker representation test.

## Required Evidence Before Scaling Beyond Envelope

- measured production concurrency;
- execution duration distribution;
- request throughput;
- persistence I/O rate;
- external API/AI consumption;
- failure rate and recovery frequency.
